## 项目介绍：AI气象大模型综合展示平台

“AI气象大模型综合展示平台” 是一个基于 Streamlit 构建的 Web 应用，旨在展示人工智能在气象预测中的应用与创新。该项目未使用 RAG（检索增强生成）技术，而是通过三大核心模块——**ResNet**、**Pangu** 和 **Agent**——实现了模型对比、动态预报和智能交互功能。以下是对每个模块的详细介绍：

### 1. ResNet 模块

- **功能**：对比基于 `climate-learn` 框架训练的 ResNet 模型与传统 Persistence 基准模型在 24 小时温度和位势高度预测中的表现。
    
- **特点**：通过并列展示两者的预测 GIF 文件（存储于 `data_visuals/resnet_climatelearn`），直观呈现 ResNet 在精度上的提升。
    
- **技术细节**：使用 Streamlit 的选项卡和列布局展示可视化结果，用户可清晰比较 AI 模型与传统方法的差异。
    

### 2. Pangu 模块

- **功能**：展示华为“盘古”气象大模型的动态天气预报，支持多种预报类型（如天气系统、2米温度分布）和时间间隔（1h、3h、6h、24h）。
    
- **特点**：用户可通过侧边栏选择预报类型和间隔，查看对应的动态动画（存储于 `data_visuals/pangu_weather`），并支持下载 GIF 文件。
    
- **技术细节**：基于 PyTorch 和 CUDA 实现高性能推理，结合 Matplotlib 生成动画，提升预测的可视化效果。
    

### 3. Agent 模块

- **功能**：提供 6h、12h、24h 和 48h 的温度预测，并支持自然语言交互。
    
- **特点**：通过集成学习的最优策略（如下所述），结合本地 7B 模型，智能回答用户查询，并模拟温度数据。
    
    - **6h 预测**：6 次迭代 1h 模型（MSE: 0.7186）
        
    - **12h 预测**：12 次迭代 1h 模型（MSE: 2.4548）
        
    - **24h 预测**：1 次迭代 24h 模型（MSE: 1.6175）
        
    - **48h 预测**：2 次迭代 24h 模型（MSE: 2.5196）
        
- **技术细节**：使用 Prompt 模板引导模型选择策略，Streamlit 的聊天界面增强交互体验。
